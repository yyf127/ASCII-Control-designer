# ASCII UI 设计器

![License](https://img.shields.io/badge/license-MIT-green)
![HTML](https://img.shields.io/badge/HTML-5-orange)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![No Dependencies](https://img.shields.io/badge/dependencies-0-brightgreen)

一个仿 **VB6 控件设计器** 的纯前端 ASCII 字符画 UI 工具。  
无需安装、无需构建，单个 HTML 文件即可运行。  
拖拽摆放控件、用 SmartArt 画流程图、用层级树表达目录结构，最后一键导出纯文本字符画。

## ✨ 功能特性

- **可视化拖拽设计** —— 从工具箱选择控件，在网格画布上拖拽创建，位置与尺寸以字符格为单位。
- **18 种控件** —— 按钮、标签、文本框、复选框、单选框、框架、组合框、列表框、图片框、滚动条、计时器、层级树等。
- **SmartArt 智能图形** —— 5 大类共 14 种模板，图形会根据容器尺寸和条目内容自动重排。
- **层级树** —— 用前导空格表达层级，自动生成 `├─ └─ │` 连接线，支持 4 种连接线样式。
- **容器联动** —— 框架内的子控件会跟随框架一起移动、删除，同时子控件仍可独立选中。
- **实时属性面板** —— 选中任意控件后，可在右侧面板修改坐标、尺寸、标题、条目等属性。
- **纯文本导出** —— 一键导出 ASCII 字符画，支持中文，汉字之间不会插入多余空格。
- **撤销清空** —— 误点清空画布后可一键恢复。
- **零依赖** —— 单个 HTML 文件，双击即用。

## 🚀 快速开始

1. **下载**  
   将仓库中的 `index.html` 保存到本地。

2. **打开**  
   双击文件，用任意现代浏览器打开。

3. **开始设计**  
   - 从左侧工具箱点击一个控件，在中央画布上拖拽即可创建。
   - 选中控件后，在右侧属性面板编辑属性。
   - 点击顶栏「导出 ASCII」查看并复制生成的字符画。

## 🖱 基础操作

### 创建控件

1. 在左侧工具箱点击一个控件类型（按钮高亮，鼠标变为十字）。
2. 在画布上按住左键拖拽，松开后按拖出的范围创建控件。
3. 单点画布则按该控件的默认尺寸创建。

### 选择与移动

| 操作 | 效果 |
|------|------|
| 点击控件内部 | 选中该控件 |
| 点击画布空白 | 取消选中 |
| 拖拽控件内部 | 移动控件 |
| 拖拽右下角 2×2 格 | 调整控件大小 |
| 方向键 | 移动 1 格 |
| `Shift` + 方向键 | 调整尺寸 1 格 |
| `Alt` + 点击 | 穿透选中容器（框架） |

### 编辑属性

选中控件后，右侧属性面板列出可编辑字段，包括：

- **X / Y 坐标**、**宽度 / 高度**（字符格）
- **名称（Name）**
- **标题（Caption）** / **文本（Text）** / **条目（Items）**
- **模板（Template）**（SmartArt 专用）
- **连接线样式（TreeStyle）**（层级树专用）

## 🎨 SmartArt 智能图形

SmartArt 按类别拆分为 5 个独立控件，每个类别只包含本类模板。选中后通过右侧「模板」下拉框切换。

### 列表

| 模板 | 效果 |
|------|------|
| 项目符号 | 每行前一个 ● 加文本 |
| 编号列表 | 每行自动编号 `1.` `2.` `3.` |
| 卡片列表 | 每项一张带边框的卡片，纵向排列 |

### 流程

| 模板 | 效果 |
|------|------|
| 水平流程 | 框从左到右，`─▶` 连接 |
| 垂直流程 | 框从上到下，`│` + `▼` 连接，连接线随高度自动变长 |
| 阶梯流程 | 框逐步向右下移动，`│` + `└─▶` 折线连接下一框左侧 |

### 循环

| 模板 | 效果 |
|------|------|
| 水平循环 | 框水平排列，底部用 `└────┘` 回环到第一框 |
| 垂直循环 | 框垂直排列，右侧用 `┐ ─ ┘` 回环到第一框 |

两个模板均支持任意数量阶段，N 个框自动分配宽度或高度。

### 层次结构

| 模板 | 效果 |
|------|------|
| 正向向下 | 根在上，子节点在下展开 |
| 反向向下 | 子节点在上，根在下 |
| 水平向右 | 根在左，子节点向右展开 |
| 水平向左 | 根在右，子节点向左展开 |
| 上下双向 | 第 1 行顶部，中间行子节点，最后 1 行底部 |

**上下双向**示例见上方[效果预览](#-效果预览)。

### 时间线

| 模板 | 效果 |
|------|------|
| 水平时间线 | 横轴，节点上下交替标注 |
| 垂直时间线 | 竖轴，节点左右交替标注 |

## 🌳 层级树（TreeView）

层级树是独立控件，用于表达目录、对象树等纯文本层级结构。

1. 从工具箱拖出一个「层级树」。
2. 在右侧「条目」框中，每行写一个节点。
3. 用**前导空格**表示层级，缩进越深层级越低。
4. 缩进宽度任意（2 空格、3 空格、Tab 均可），工具会自动归一化。

**连接线样式**（属性面板切换）：

| 样式 | 效果 |
|------|------|
| Unicode 框线 | `├─ └─ │`（默认） |
| ASCII 兼容 | `+- \- \|` |
| 圆点 | `•` |
| 纯缩进 | 无符号，仅缩进 |

## 📦 容器（框架）行为

框架（Frame）是一种容器控件，用于把若干控件视觉上归为一组。

- **拖动框架**：内部子控件一起移动。
- **方向键移动框架**：子控件一起移动。
- **删除框架**：内部子控件一并删除。
- **修改框架坐标**：子控件跟随位移。
- **子控件仍可独立选中**：点击框架内的按钮、标签等，优先选中这些控件。
- **`Alt` + 点击**：穿透选中框架本身。

子控件的判定规则：控件完全位于框架客户区内（框架边框内侧 1 格）时，视为其子控件。

## 📤 导出 ASCII

点击顶栏「导出 ASCII」按钮，弹出只读文本框显示当前画布的纯文本字符画。

- 导出结果**不含颜色**，只有字符。
- 每行末尾空白自动裁掉，空行移除。
- **汉字之间不会插入多余空格**。
- 弹窗内提供「复制到剪贴板」按钮，一键复制。

## 🛠 技术实现

- **单文件结构**：HTML + CSS + 原生 JavaScript，无第三方依赖。
- **网格渲染**：内部维护 `80 × 40` 字符网格 `grid[y][x]`，每个控件通过 `draw(c)` 写入字符与颜色，最后渲染为绝对定位的 `<div>`。
- **宽字符处理**：`charWidth()` 判断 CJK 字符占 2 格，写入时把第二格标记为 `skip`，渲染和导出时跳过。
- **命中测试**：`hitTest()` 优先返回面积最小的非容器控件，保证框架内控件可直接点中；`Alt` 键强制选中容器。
- **数据模型**：控件存于 `controls` 数组，每个控件是普通对象（`id`、`type`、`x`、`y`、`w`、`h` 及业务属性）。
- **SmartArt 模板系统**：`SMARTART_CATEGORIES` 以类别组织模板，每个模板是一个 `draw(c)` 函数，动态计算布局。
- **容器联动**：`collectDescendants()` 递归收集框架内子控件，移动 / 删除时同步处理。
